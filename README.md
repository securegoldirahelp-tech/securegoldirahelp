3-page GitHub Pages site. Deploy in under 10 minutes.

## Files

- `index.html` — Homepage
- `blog.html` — Article listing page  
- `post.html` — First blog post (What Inflation Is Quietly Doing to Your IRA)

## How to Deploy on GitHub Pages

1. Go to **github.com** → sign in (or create a free account)
2. Click the **+** icon → **New repository**
3. Name it: `ira-gold-guide` (or anything you like)
4. Set to **Public**
5. Click **Create repository**
6. Click **uploading an existing file**
7. Drag and drop all 3 HTML files → click **Commit changes**
8. Go to **Settings** → **Pages** (left sidebar)
9. Under "Branch" select `main` → click **Save**
10. Your site is live at: `https://YOUR-USERNAME.github.io/ira-gold-guide/`

Takes about 2 minutes to go live after saving.
